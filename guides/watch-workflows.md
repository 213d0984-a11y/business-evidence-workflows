# Watch the workflow before you run it

Pick the task closest to your work. Each short, silent English-captioned video illustrates an input, a result or documented review step, and the next action. Videos use owner tests or documented examples. Dates and data in saved examples are historical. The publisher maintains these Actors.

These are illustrated walkthroughs and do not show a live screen recording. They do not represent customer outcomes. The hospitality review video describes the result to inspect. Before running an example, check the Actor's current Pricing tab and set a maximum cost. A run or subsequent access to results can incur charges.
