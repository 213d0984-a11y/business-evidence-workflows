# Watch the workflow before you run it

Pick the task closest to your work. Each short, silent English-captioned video shows an Apify input form and a published result example. Videos use owner tests or documented examples. Dates and data in saved examples are historical. The publisher maintains these Actors.

The walkthroughs use edited still captures of actual screens. The form and result captures can come from different observations, and no new run was made for these videos. The historical examples do not represent customer outcomes. Before running an example, check the Actor's current Pricing tab and set a maximum cost. A run or subsequent access to results can incur charges.
